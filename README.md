# Мёртвый груз

Браузерный 2D-экшен в духе My Friend Pedro: слоу-мо, сальто сквозь пули и стрельба в полёте. Нуар с юмором в космосе.

Капитан Ярра Корд и болтливый дрон Тостер высаживаются на рудовоз «Мнемозина», пропавший три года назад. В трюме ждёт контейнер 0-17 за солидное вознаграждение, а на борту правят андроиды, перебившие экипаж.

## Как запустить

Открой `index.html` в браузере. Сборка и сервер не нужны: вся игра лежит в одном файле.

## Управление

| Клавиши | Действие |
|---|---|
| A / D | Бег |
| W / Пробел | Прыжок; в воздухе — ещё один, у стены — отскок |
| Мышь, ЛКМ | Прицел и огонь |
| Shift | Замедлить время, пока есть фокус |
| Q / ПКМ | Сальто: пули проходят мимо |
| E | Пинок андроиду или кислородному баллону |
| S + Пробел | Спрыгнуть с мостика |
| R / Esc / M | Перезарядка, пауза, звук |

На сенсорных экранах появляются экранные кнопки.

## Главы

1. Стыковочный шлюз
2. Жилой модуль
3. Гидропоника
4. Реактор — босс: главный инженер
5. Пробоина — невесомость и выход на обшивку
6. Трюм — краны с контейнерами и сканеры
7. Мостик — два босса и выбор из трёх концовок

Между главами идут катсцены. Прогресс по главам и открытые концовки хранятся в `localStorage` браузера.
